# Grenade Homebrew tap

The Homebrew tap of [Grenade](https://www.holdgrenade.com): watch and answer the AI coding agents (Claude Code, Codex, a shell) running in your Mac's terminals from your phone.

## Install

```bash
brew install holdgrenade/tap/grenade
grenade setup
```

`grenade setup` checks the requirements, starts the daemon at login, offers remote access through a relay, and shows a QR code that pairs your phone. It asks before it changes anything.

Then get an app and scan the code: [Grenade: Agent Remote](https://apps.apple.com/app/grenade-agent-remote/id6818136871) for iPhone, or the Mac app, from the same tap or as [a download](https://downloads.holdgrenade.com/mac/Grenade.dmg). `grenade setup` offers to install it too. Every step is on the [install page](https://www.holdgrenade.com/install).

```bash
brew install --cask holdgrenade/tap/grenade-app
```

## Update and remove

Grenade keeps itself up to date: the daemon installs a new version through Homebrew when there is one, and your sessions keep running. `brew pin grenade` stops that.

```bash
brew upgrade grenade        # update now
grenade service remove      # before removing: stop the daemon starting at login
brew uninstall grenade
```

## Formulas and casks

| Name | What it installs |
| --- | --- |
| `grenade` (formula) | The `grenade` CLI and the `grenaded` daemon. Needs macOS; brings `node` and `tmux`. |
| `grenade-app` (cask) | The Grenade Mac app, into `/Applications`: the same notarized disk image as the download. It updates itself, so `brew upgrade` leaves it alone (`auto_updates`). Needs macOS 26. |

The formula is generated by a release of [`grenade-cli`](https://github.com/holdgrenade/grenade-cli), where the source is, and the cask by a release of the Mac app. Problems and questions: [issues on `grenade-cli`](https://github.com/holdgrenade/grenade-cli/issues).
